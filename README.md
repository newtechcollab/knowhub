# knowhub
Enterprise Knowledge Hub (in short, knowhub) that stores and provides operational and business information from different enterprise systems along with relationship between them. Currently, it extracts information from local files/folders, JIRA, Confluence, ServiceNow and Salesforce. It also keeps the hub in-sync with these enterprise systems as and when any information is added/modified/deleted therein.

After retrieving the data from enterprise systems, the hub scrubs the data to anonymize confidential data such as PII data, customer information. You can also extend this easily to implement any specific data privacy pertaining to your organization or use case.
